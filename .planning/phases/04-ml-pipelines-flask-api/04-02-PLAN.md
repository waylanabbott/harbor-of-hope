  emotion_map = {

      'Sad': 5, 'Calm': 6, 'Hopeful': 7, 'Happy': 8
  }
  pr['start_score'] = pr['emotional_state_observed'].map(emotion_map)

  for intervention in ['Caring', 'Teaching', 'Legal Services', 'Healing']:

**Step 1: Notebook 07 — Donation Forecasting (ML-07, Predictive Regression)**
Create `ml-pipelines/notebooks/07-donation-forecasting.ipynb` using nbformat.

Section 1 — Problem Framing:
- Business problem: Forecast future monthly donation totals to support financial planning
- Approach: Predictive (regression — NOT time-series ARIMA due to limited data points)
- Target: monthly total donation amount
- Success metric: RMSE, R-squared

Section 2 — Data Acquisition and Preparation:
- Load `donations.csv` (420 rows)
- Parse donation_date to datetime
- Aggregate to monthly totals: `monthly = donations.groupby(pd.Grouper(key='donation_date', freq='MS')).agg(total_amount=('amount', 'sum'), donation_count=('donation_id', 'count')).reset_index()`
- Engineer time-based features:
  - month (1-12, for seasonality)
  - year
  - month_index (sequential: 0, 1, 2, ... for trend)
  - lag_1: previous month total
  - lag_3: 3-month lag
  - rolling_mean_3: 3-month rolling average
  - rolling_mean_6: 6-month rolling average
- Drop rows with NaN from lag/rolling features
- Numeric features: month, year, month_index, lag_1, lag_3, rolling_mean_3, rolling_mean_6, donation_count
- Train/test: use last 20% of months as test (temporal split — do NOT shuffle time series)
- random_state=42 where applicable

Section 3 — Exploration:
- Line chart of monthly donation totals over time
- Seasonal pattern (mean by month)
- Rolling average overlay on time series
- Distribution of monthly totals

Section 4 — Modeling:
- ColumnTransformer with StandardScaler for all numeric features
- Model progression (regression, not classification):
  1. LinearRegression — baseline
  2. DecisionTreeRegressor(max_depth=3, random_state=42)

  4. GradientBoostingRegressor(n_estimators=100, max_depth=2, random_state=42)
