Create ReportsController.cs:
- Namespace: `HarborOfHope.API.Controllers`
- Route: `api/[controller]`
- Policy: `Authorize(Policy = AuthPolicies.AdminOnly)` -- use `HarborOfHope.API.Data` namespace (NOT Infrastructure)
- Primary constructor injection: `(AppDbContext db, MlPredictionService mlService)`

**Endpoint 1 - GET donation-trends (RPT-01):**
- Query `db.Donations` where `DonationDate != null`
- Group by `DonationDate.Value.Year` and `DonationDate.Value.Month`
- Select new `DonationTrendDto` with Month as `$"{year}-{month:D2}"`, Sum of Amount, Count
- Order by Month ascending
- Return `Ok(trends)`

**Endpoint 2 - GET resident-outcomes (RPT-02):**
- Query `db.Residents` where `ReintegrationStatus != null`
- Group by `ReintegrationStatus`
- Select new `ResidentOutcomeDto(status, count)`
- Order by Count descending
- Return `Ok(outcomes)`

**Endpoint 3 - GET safehouse-comparison (RPT-03):**
- Query `db.Safehouses` with `.Include(s => s.Residents).Include(s => s.MonthlyMetrics)`
- For each safehouse, compute:
  - ResidentCount = s.Residents.Count
  - AvgHealthScore = average of MonthlyMetrics.AvgHealthScore (or 0 if none)
  - AvgEducationProgress = average of MonthlyMetrics.AvgEducationProgress (or 0 if none)
  - TotalIncidents = sum of MonthlyMetrics.IncidentCount (or 0 if none)
- Use `.Select()` to project into `SafehouseComparisonDto`
- Order by ResidentCount descending
- Return `Ok(comparisons)`

**Endpoint 4 - POST batch-churn (DONR-06):**
- Accept `[FromBody] BatchChurnRequest request`
- Limit to max 100 supporter IDs per request (return 400 if exceeded)
- For each supporterId in request.SupporterIds:
  a. Load supporter from `db.Supporters` (get SupporterType, AcquisitionChannel, Region)
  b. Load monetary donations: `db.Donations.Where(d => d.SupporterId == id && d.DonationType == "Monetary")`
  c. Compute RFM features:
     - referenceDate = max DonationDate across ALL monetary donations (compute once before loop)
     - recency = (referenceDate - lastDonationDate).TotalDays (or 9999 if no donations)
     - frequency = count of monetary donations
     - monetary_total = sum of Amount
     - monetary_avg = average of Amount (or 0)
     - monetary_std = standard deviation of Amount (or 0)
     - tenure_days = (referenceDate - firstDonationDate).TotalDays (or 0)
  d. Build features dictionary with all 9 keys (6 numeric + supporter_type, acquisition_channel, region)
  e. Call `mlService.PredictAsync("donor-churn", features)`
  f. If result is null (ML API down), return ChurnPredictionDto with RiskLevel="Unknown", ChurnProbability=0
  g. Otherwise extract RiskLevel from result.RiskLevel (or "Unknown"), ChurnProbability from result.Probabilities[0][1] (or 0)
- Return `Ok(predictions)`
- Note: Use `Task.WhenAll` pattern INSTEAD of sequential calls to avoid N+1 latency. Load all supporters and donations in bulk first, then call ML API sequentially (Flask is single-threaded).

IMPORTANT: All string values passed to features dict must be boxed as `object` (the dict is `Dictionary<string, object>`).
