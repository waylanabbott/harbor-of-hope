**Program.cs — Serve React SPA as static files:**

After the existing middleware pipeline (after `app.MapControllers()`), add SPA fallback routing so that any request not matching an API route or static file serves `index.html`:

```csharp
// Serve React SPA static files
app.UseStaticFiles(); // Serves from wwwroot/

// SPA fallback: any non-API, non-file request returns index.html
app.MapFallbackToFile("index.html");
```

IMPORTANT: `UseStaticFiles()` must come AFTER `UseAuthorization()` and BEFORE `MapFallbackToFile`. The `MapFallbackToFile` line must come AFTER `app.MapControllers()` so API routes take precedence.

Also update the CORS policy to be conditional — in production, the frontend is served from the same origin so CORS is less critical, but keep it for the Flask API calls:

```csharp
// Keep existing CORS for development
// In production, React is served from same origin so no CORS needed for frontend
```

No change to CORS is needed since the SPA will be same-origin in production. Keep existing CORS config for development.

**deploy.sh — Azure CLI deployment script:**

The script should:

1. Accept parameters or use defaults:
   - `RESOURCE_GROUP` (default: `harborofhope-rg`)
   - `LOCATION` (default: `eastus`)
   - `APP_NAME` (default: `harborofhope`)
   - `FLASK_APP_NAME` (default: `harborofhope-ml`)
   - `DB_SERVER_NAME` (default: `harborofhope-db`)
   - `DB_ADMIN_USER` (default: `hohadmin`)
   - `DB_ADMIN_PASSWORD` — REQUIRED, must be passed as argument or environment variable
   - `DB_NAME` (default: `harborofhope`)

2. Check prerequisites: `az` CLI installed, user logged in (`az account show`).

3. Create Resource Group:
   ```bash
   az group create --name $RESOURCE_GROUP --location $LOCATION
   ```

4. Create Azure Database for PostgreSQL Flexible Server (per DEPLOY-02):
   ```bash
   az postgres flexible-server create \
     --resource-group $RESOURCE_GROUP \
     --name $DB_SERVER_NAME \
     --location $LOCATION \
     --admin-user $DB_ADMIN_USER \
     --admin-password $DB_ADMIN_PASSWORD \
     --sku-name Standard_B1ms \
     --tier Burstable \
     --storage-size 32 \
     --version 16 \
     --yes
   ```
   Then create the database:
   ```bash
   az postgres flexible-server db create \
     --resource-group $RESOURCE_GROUP \
     --server-name $DB_SERVER_NAME \
     --database-name $DB_NAME
   ```
   Allow Azure services:
   ```bash
   az postgres flexible-server firewall-rule create \
     --resource-group $RESOURCE_GROUP \
     --name $DB_SERVER_NAME \
     --rule-name AllowAzureServices \
     --start-ip-address 0.0.0.0 \
     --end-ip-address 0.0.0.0
   ```

5. Create App Service Plan (shared between .NET and Flask):
   ```bash
   az appservice plan create \
     --resource-group $RESOURCE_GROUP \
     --name "${APP_NAME}-plan" \
     --sku B1 \
     --is-linux
   ```

6. Create .NET App Service (per DEPLOY-01):
   ```bash
   az webapp create \
     --resource-group $RESOURCE_GROUP \
     --plan "${APP_NAME}-plan" \
     --name $APP_NAME \
     --runtime "DOTNETCORE:10.0"
   ```
   Configure app settings:
   ```bash
   CONN_STRING="Host=${DB_SERVER_NAME}.postgres.database.azure.com;Database=${DB_NAME};Username=${DB_ADMIN_USER};Password=${DB_ADMIN_PASSWORD};SSL Mode=Require;Trust Server Certificate=true"

   az webapp config connection-string set \
     --resource-group $RESOURCE_GROUP \
     --name $APP_NAME \
     --connection-string-type PostgreSQL \
     --settings DefaultConnection="$CONN_STRING"

   az webapp config appsettings set \
     --resource-group $RESOURCE_GROUP \
     --name $APP_NAME \
     --settings \
       MlApiUrl="https://${FLASK_APP_NAME}.azurewebsites.net" \
       ASPNETCORE_ENVIRONMENT=Production
   ```

7. Create Flask App Service (per DEPLOY-03):
   ```bash
   az webapp create \
     --resource-group $RESOURCE_GROUP \
     --plan "${APP_NAME}-plan" \
     --name $FLASK_APP_NAME \
     --runtime "PYTHON:3.12"
   ```
   Configure Flask settings:
   ```bash
   az webapp config appsettings set \
     --resource-group $RESOURCE_GROUP \
     --name $FLASK_APP_NAME \
     --settings \
       ALLOWED_ORIGINS="https://${APP_NAME}.azurewebsites.net" \
       SCM_DO_BUILD_DURING_DEPLOYMENT=true
   ```
   Set startup command:
   ```bash
   az webapp config set \
     --resource-group $RESOURCE_GROUP \
     --name $FLASK_APP_NAME \
     --startup-file "gunicorn --bind=0.0.0.0:8000 flask_api.app:app"
   ```

8. Build and deploy frontend:
   ```bash
   echo "Building frontend..."
   cd frontend && npm ci && npm run build && cd ..
   ```

9. Publish and deploy .NET backend (includes wwwroot from step 8):
   ```bash
   echo "Publishing .NET backend..."
   cd backend/HarborOfHope.API
   dotnet publish -c Release -o ./publish
   cd publish
   zip -r ../../../azure-deploy/backend.zip .
   cd ../../..

   az webapp deployment source config-zip \
     --resource-group $RESOURCE_GROUP \
     --name $APP_NAME \
     --src azure-deploy/backend.zip
   ```

10. Deploy Flask API:
    ```bash
    echo "Deploying Flask API..."
    cd ml-pipelines
    zip -r ../azure-deploy/flask.zip flask_api/ models/
    cd ..

    az webapp deployment source config-zip \
      --resource-group $RESOURCE_GROUP \
      --name $FLASK_APP_NAME \
      --src azure-deploy/flask.zip
    ```

11. Print summary:
    ```bash
    echo "Deployment complete!"
    echo "Main site: https://${APP_NAME}.azurewebsites.net"
    echo "Flask API: https://${FLASK_APP_NAME}.azurewebsites.net/health"
    echo "Database: ${DB_SERVER_NAME}.postgres.database.azure.com"
    ```

Make the script executable: `chmod +x azure-deploy/deploy.sh`
